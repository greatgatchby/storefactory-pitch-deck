Why now

Three things became true at once —
none of them were true in 2022.

01

Models stopped scaffolding and started maintaining

Agentic coding — tool use, file edits, running code in a sandbox and reading the result — means a model can change a live application on the twentieth request as reliably as it built it on the first. A one-shot generator produces a demo. This produces a product a merchant can keep.

02

Every layer of commerce became an API

Headless commerce, headless CMS, payments, transactional email, DNS and hosting are all API-first now. A complete business stack can be provisioned by a program instead of assembled by a person — which is exactly the part agencies were charging five figures for.

ThenA developer wires the stack by hand
NowOne API call per merchant, start to finish
03

Compute got cheap enough to give everyone their own

Containerised backends on commodity hardware put a real, isolated stack per merchant — their own database, their own admin, their own deployments — inside a £25/month price point. Isolation used to be an enterprise line item. It is now a rounding error.

NowA dedicated stack each, at SMB prices
